# Work Timer

A customizable timer with work and pause intervals, 
built with Python and Tkinter and works on Linux.

This project is a practice exercise.

## Description

This timer allows you to set custom work and pause intervals, 
making it ideal for techniques like the Pomodoro Technique. 
The timer alternates between work and pause periods, 
notifying you with a sound and a message when it's time to switch.

## Features

- Customizable work and pause durations.
- Simple and intuitive GUI.
- Real-time clock display.
- Sound notification when switching between work and pause modes.
- Message box notifications for mode switches.

## Installation

To run this timer, you need Python and the required dependencies. 
Follow these steps:

1. Clone this repository or download the code.
2. Make sure you have Python installed on your system.
3. Install the required dependencies.

## Usage

1. Enter the desired work and pause durations in minutes and click reset.
2. Click the "Start" button to begin the timer.
3. The timer will alternate between work and pause intervals automatically.
4. Use the "Stop" button to pause the timer and the "Reset" button to reset it.

## Requirements

- Python 3.x
- Tkinter (usually comes with Python)
- A sound file for notifications 
  (default: `/usr/share/sounds/sound-icons/prompt.wav`)
- Linux distribution
